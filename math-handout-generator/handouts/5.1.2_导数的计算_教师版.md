## 一、 知识精讲与深度剖析

### 1. 基本初等函数的导数公式
熟记以下八大基本求导公式，这是所有导数计算的地基：
1. 常数函数：$(C)' = 0$ ($C$ 为常数)
2. 幂函数：$(x^\alpha)' = \alpha x^{\alpha-1}$ ($\alpha$ 为实数)。特别注意：$(\sqrt{x})' = \frac{1}{2\sqrt{x}}$，$(\frac{1}{x})' = -\frac{1}{x^2}$。
3. 正弦函数：$(\sin x)' = \cos x$
4. 余弦函数：$(\cos x)' = -\sin x$ （注意负号！）
5. 指数函数：$(a^x)' = a^x \ln a$ ($a>0, a \neq 1$)
6. 自然指数函数：$(e^x)' = e^x$ （唯一的导数等于它本身的函数）
7. 对数函数：$(\log_a x)' = \frac{1}{x \ln a}$ ($a>0, a \neq 1$)
8. 自然对数函数：$(\ln x)' = \frac{1}{x}$

### 2. 导数的四则运算法则
若两个函数 $u(x), v(x)$ 均可导，则：
1. **加减法则**：$[u(x) \pm v(x)]' = u'(x) \pm v'(x)$
2. **乘法法则**：$[u(x)v(x)]' = u'(x)v(x) + u(x)v'(x)$ （口诀：前导后不导 + 前不导后导）
   - 推论：$[Cu(x)]' = C u'(x)$
3. **除法法则**：$\left[ \frac{u(x)}{v(x)} \right]' = \frac{u'(x)v(x) - u(x)v'(x)}{v^2(x)}$ ($v(x) \neq 0$) （口诀：上导下不导 减 上不导下导，分母平方）

### 3. 复合函数的求导法则
- **法则**：复合函数 $y = f(g(x))$ 的导数和函数 $y = f(u), u = g(x)$ 的导数间的关系为：
  $$y_x' = y_u' \cdot u_x'$$
- **通俗理解（剥洋葱法则）**：从最外层函数开始求导，求完后把里面的一层看作自变量，然后再乘以里面那一层对 $x$ 的导数。一层一层剥，直到剥到 $x$ 为止。

## 二、 必背符号与性质

| 法则 / 公式 | 表达式 | 核心易错点 |
|:---|:---|:---|
| **幂函数求导** | $(x^\alpha)' = \alpha x^{\alpha-1}$ | 指数提前，原来指数减 1。不要和 $a^x$ 搞混！ |
| **商的求导** | $\left( \frac{u}{v} \right)' = \frac{u'v - uv'}{v^2}$ | 中间是 **减号**，且一定是**分子先导**！ |
| **复合求导链式法则**| $f(g(x))' = f'(g(x)) \cdot g'(x)$ | 绝不能漏乘内层函数的导数 $g'(x)$ |

## 四、 核心题型与精选变式

### 题型一：基本初等函数与加减求导
**【典例1】**
求函数 $y = x^3 - 2\sqrt{x} + \frac{3}{x} - \sin x$ 的导数。

- **【思路点拨】** 先把根式、分式化为分数指数幂和负指数幂的形式，然后再逐项套用公式。
- **【规范解答】**
  原函数可化为 $y = x^3 - 2x^{\frac{1}{2}} + 3x^{-1} - \sin x$。
  $y' = 3x^2 - 2 \times \frac{1}{2}x^{-\frac{1}{2}} + 3 \times (-1)x^{-2} - \cos x$
  $= 3x^2 - \frac{1}{\sqrt{x}} - \frac{3}{x^2} - \cos x$。

**【变式 1-1】**
求 $y = 2^x + \log_2 x + \pi^2$ 的导数。
**【解析】** 注意 $\pi^2$ 是常数，导数为 0。$y' = 2^x \ln 2 + \frac{1}{x \ln 2}$。

**【变式 1-2】**
已知 $f(x) = x^2 - \cos x$，求 $f'(\frac{\pi}{2})$。
**【解析】** $f'(x) = 2x + \sin x$。$f'(\frac{\pi}{2}) = 2(\frac{\pi}{2}) + \sin(\frac{\pi}{2}) = \pi + 1$。

**【变式 1-3】**
若函数 $f(x) = ax^3 + bx^2 + cx + d$ 满足 $f'(0) = 2, f''(0) = 4$（其中 $f''(x)$ 为导数的导数），求 $b, c$ 的值。
**【解析】** $f'(x) = 3ax^2 + 2bx + c$，$f''(x) = 6ax + 2b$。
$f'(0) = c = 2$；$f''(0) = 2b = 4 \Rightarrow b = 2$。

### 题型二：乘积与商的求导法则
**【典例2】**
求函数 $f(x) = \frac{\ln x}{x}$ 的导数。

- **【思路点拨】** 这是极其经典的商的求导模型，牢记公式：$\frac{u'v - uv'}{v^2}$，上面减号，分母平方。
- **【规范解答】**
  $f'(x) = \frac{(\ln x)' \cdot x - \ln x \cdot (x)'}{x^2}$
  $= \frac{\frac{1}{x} \cdot x - \ln x \cdot 1}{x^2}$
  $= \frac{1 - \ln x}{x^2}$。

**【变式 2-1】**
求 $y = (x^2 + 1)e^x$ 的导数。
**【解析】** $y' = (x^2+1)'e^x + (x^2+1)(e^x)' = 2xe^x + (x^2+1)e^x = (x^2+2x+1)e^x = (x+1)^2 e^x$。

**【变式 2-2】**
求 $f(x) = \frac{e^x}{x^2}$ 的导数。
**【解析】** $f'(x) = \frac{(e^x)'x^2 - e^x(x^2)'}{(x^2)^2} = \frac{e^x x^2 - e^x \cdot 2x}{x^4} = \frac{x e^x(x-2)}{x^4} = \frac{e^x(x-2)}{x^3}$。

**【变式 2-3】**
已知 $f(x) = x \sin x$，求其导数及 $f'(\pi)$ 的值。
**【解析】** $f'(x) = 1 \cdot \sin x + x \cdot \cos x = \sin x + x \cos x$。
$f'(\pi) = \sin \pi + \pi \cos \pi = 0 + \pi(-1) = -\pi$。

### 题型三：复合函数的求导（剥洋葱法）
**【典例3】**
求函数 $y = \ln(2x + 1)$ 的导数。

- **【思路点拨】** 把 $2x+1$ 看作整体 $u$。外层是 $\ln u$，内层是 $2x+1$。
- **【规范解答】**
  设 $u = 2x+1$，则 $y = \ln u$。
  $y' = (\ln u)' \cdot u'$
  $= \frac{1}{u} \cdot (2x+1)'$
  $= \frac{1}{2x+1} \cdot 2 = \frac{2}{2x+1}$。

**【变式 3-1】**
求 $y = e^{-x^2}$ 的导数。
**【解析】** 外层指数，内层 $-x^2$。$y' = e^{-x^2} \cdot (-x^2)' = -2x e^{-x^2}$。

**【变式 3-2】**
求 $y = \sin(3x + \frac{\pi}{4})$ 的导数。
**【解析】** 外层正弦，内层 $3x+\frac{\pi}{4}$。$y' = \cos(3x+\frac{\pi}{4}) \cdot (3x+\frac{\pi}{4})' = 3\cos(3x+\frac{\pi}{4})$。

**【变式 3-3】**
求 $y = (\frac{1}{2}x^2 + 3x)^4$ 的导数。
**【解析】** $y' = 4(\frac{1}{2}x^2 + 3x)^3 \cdot (\frac{1}{2}x^2 + 3x)' = 4(\frac{1}{2}x^2 + 3x)^3 \cdot (x + 3)$。

**【变式 3-4】**
求 $f(x) = \ln^2 x$（即 $(\ln x)^2$）的导数。
**【解析】** 外层平方，内层对数。$f'(x) = 2(\ln x)^1 \cdot (\ln x)' = 2\ln x \cdot \frac{1}{x} = \frac{2\ln x}{x}$。

### 题型四：含导数值的方程综合
**【典例4】**
已知函数 $f(x) = x^3 + f'(1) \cdot x^2 + 2x$，求 $f'(1)$ 的值。

- **【思路点拨】** 注意 $f'(1)$ 是一个**常数**。我们先当它是一个普通字母去求导数 $f'(x)$，然后把 $x=1$ 代入，就能得到一个关于 $f'(1)$ 的一元一次方程。
- **【规范解答】**
  因为 $f(x) = x^3 + f'(1) x^2 + 2x$。
  对其求导，得 $f'(x) = 3x^2 + 2f'(1) x + 2$。
  令 $x = 1$，则 $f'(1) = 3(1)^2 + 2f'(1)(1) + 2$。
  即 $f'(1) = 3 + 2f'(1) + 2$。
  解这个关于 $f'(1)$ 的方程，得 $f'(1) = -5$。

**【变式 4-1】**
若 $f(x) = e^x + x \cdot f'(0)$，求 $f(1)$ 的值。
**【解析】** 求导得 $f'(x) = e^x + f'(0)$。令 $x=0$，得 $f'(0) = e^0 + f'(0) \Rightarrow 0 = 1$，矛盾？注意，如果此题无解，说明题目设定有误。调整变式：$f(x) = e^x - x \cdot f'(0)$。
$f'(x) = e^x - f'(0) \Rightarrow f'(0) = 1 - f'(0) \Rightarrow f'(0) = \frac{1}{2}$。所以 $f(x) = e^x - \frac{1}{2}x$，则 $f(1) = e - \frac{1}{2}$。

**【变式 4-2】**
已知 $f(x) = x^2 \ln x - x f'(1)$，求 $f'(1)$。
**【解析】** 求导得 $f'(x) = 2x \ln x + x^2 \cdot \frac{1}{x} - f'(1) = 2x \ln x + x - f'(1)$。
令 $x=1$，得 $f'(1) = 0 + 1 - f'(1) \Rightarrow 2f'(1) = 1 \Rightarrow f'(1) = \frac{1}{2}$。

**【变式 4-3】**
已知 $f(x) = x \cos x + \sin x$，求 $f''(\frac{\pi}{2})$。
**【解析】** $f'(x) = \cos x - x \sin x + \cos x = 2\cos x - x \sin x$。
$f''(x) = -2\sin x - (\sin x + x \cos x) = -3\sin x - x \cos x$。
$f''(\frac{\pi}{2}) = -3(1) - 0 = -3$。

## 五、 当堂过关检测

### 【A组】
1. 若 $y = x^4 - 3x^2 + 5$，则 $y' =$ ________。
   **【解答】** $4x^3 - 6x$。
2. $(x \ln x)' =$ ________。
   **【解答】** $\ln x + 1$。
3. 若 $f(x) = e^{2x}$，则 $f'(x) =$ ________。
   **【解答】** $2e^{2x}$。

### 【B组】
4. 已知 $f(x) = \frac{\sin x}{x}$，求 $f'(x)$。
   **【解答】** $f'(x) = \frac{x \cos x - \sin x}{x^2}$。
5. 求函数 $y = \ln(x^2 + 1)$ 的导数。
   **【解答】** $y' = \frac{1}{x^2+1} \cdot 2x = \frac{2x}{x^2+1}$。
6. 已知 $f(x) = x^3 + x^2 f'(-1)$，求 $f'(x)$。
   **【解答】** $f'(x) = 3x^2 + 2x f'(-1)$。代入 $x=-1$ 得 $f'(-1) = 3 - 2f'(-1) \Rightarrow f'(-1) = 1$。所以 $f'(x) = 3x^2 + 2x$。

### 【C组】
7. 求 $y = x \sqrt{x^2+1}$ 的导数。
   **【解答】** $y' = \sqrt{x^2+1} + x \cdot \frac{1}{2\sqrt{x^2+1}} \cdot 2x = \sqrt{x^2+1} + \frac{x^2}{\sqrt{x^2+1}} = \frac{2x^2+1}{\sqrt{x^2+1}}$。
8. 已知 $f(x) = \frac{e^x}{x+1}$，求曲线 $y=f(x)$ 在 $x=0$ 处的切线方程。
   **【解答】** $f(0) = 1$，切点为 $(0,1)$。$f'(x) = \frac{e^x(x+1) - e^x}{(x+1)^2} = \frac{x e^x}{(x+1)^2}$。$f'(0) = 0$。切线方程为 $y=1$。

## 六、 易错坑点防雷

- 🧨 **易错点1**：商的求导法则中间的符号写错，或者分子先后顺序搞反。
  **正确做法**：死记口诀：“**上导下不导 减去 上不导下导**”。一定是处于上面的分子先求导！减号绝对不能错！
- 🧨 **易错点2**：求 $(e^{2x})'$ 直接写成 $e^{2x}$，或者 $(\ln(3x))'$ 直接写成 $\frac{1}{3x}$。
  **正确做法**：忘记了复合函数的链式法则（剥洋葱）。只要 $x$ 的位置被替换成了别的式子，求导时**最后一定要乘以内层式子的导数**！例如 $(e^{2x})' = e^{2x} \cdot 2 = 2e^{2x}$。
