# 🎯 导数极值点偏移问题 题型攻坚与拓展

## 💡 一、 命题密码解析与核心知识点总结
- **核心概念透析（什么是极值点偏移？）**：
  对于函数 $f(x)$，若其在某区间内存在唯一极值点 $x_0$。当 $f(x_1) = f(x_2)$（且 $x_1 \neq x_2$）时，如果函数的图象关于直线 $x = x_0$ 完美对称（例如普通的二次函数抛物线），那么必然有这两个点的中点 $\frac{x_1+x_2}{2} = x_0$。
  但如果函数图象是不对称的（例如受指数函数 $e^x$ 或对数函数 $\ln x$ 的影响，导致图象一侧平缓，另一侧陡峭），那么要在两侧找到高度相同的点，平缓一侧的自变量要走的距离必然大于陡峭一侧的距离。这就导致了这两个点的中点 $\frac{x_1+x_2}{2}$ 偏离了原来的极值点 $x_0$。这就是极值点偏移的几何本质。
- **考查知识点**：导数在函数单调性中的应用、双变量极值点偏移的代数证明方法（对称性构造法、对数均值不等式、比值换元法）。
- **高考占比与频次**：近 5 年高考全国卷及各地名校模拟卷压轴题绝对核心热点，常设在解答题第二问，分值占比 6~8 分。
- **常见命题形式与变体**：
  1. **和差型**：证明 $x_1+x_2 > 2x_0$ 或 $x_1+x_2 < 2x_0$（或相减等）。
  2. **积商型**：证明 $x_1 x_2 > x_0^2$ 或 $x_1 x_2 < x_0^2$。

## 🚧 二、 破题核心通法与易错防雷

- **解题通法（三大SOP模型）**：
  1. **【最核心通法：对称构造法】**
     当题目要求证明 $x_1+x_2 > 2x_0$ 时（假设 $x_1 < x_0 < x_2$），等价于证明 $x_2 > 2x_0 - x_1$。
     利用函数在极值点右侧的单调性，把自变量的大小比较，**转化为函数值的大小比较**，即证明 $f(x_2)$ 与 $f(2x_0-x_1)$ 的关系。
     由于已知 $f(x_1) = f(x_2)$，最终转化为证明 $f(x_1)$ 与 $f(2x_0-x_1)$ 的大小关系。
     **标准操作程序（SOP）**：构造一元辅助函数 $g(x) = f(x) - f(2x_0-x)$，求导判断单调性，代入极值点得出符号，从而证毕。
  2. **【对数均值法】**
     当原函数中包含复杂的指数运算，直接构造相减求导过于复杂时，考虑对 $f(x_1) = f(x_2)$ 两边同时取对数，将乘除运算降级为加减运算，再进行构造。
  3. **【比值换元法】**
     当出现齐次式或积商型偏移时，常令 $t = \frac{x_1}{x_2}$（设 $t > 1$），利用原方程消去其中一个变量，构造关于 $t$ 的单变量函数进行证明。

- **易错防雷区**：
  1. **辅助函数定义域弄错**：构造 $g(x) = f(x) - f(2x_0-x)$ 时，必须明确 $x$ 的取值范围是极值点的左侧还是右侧！如果设错左右侧，放缩不等号将完全反转。
  2. **对二次求导的畏难情绪**：偏移问题构造的新函数 $g(x)$，其一阶导数往往无法直接判断出正负号，必须坚定信念进行二次甚至三次求导！
  3. **忽略题目隐藏边界**：题目有时会附加如 $0<x_1<2$ 的条件，放缩时若没有卡紧这个边界区间，二次求导时会丢失极值判定依据。

## ✍️ 三、 经典原题重现

**【原题】**
已知函数 $f(x) = \frac{x^2}{e^{ax}}$，其中 $a>0$。
（1）若 $f(x)$ 在 $(0,2]$ 上单调递增，求 $a$ 的取值范围；
（2）当 $a=1$ 时，若 $x_1+x_2=4$ 且 $0<x_1<2$，判断 $f(x_1)$ 与 $f(x_2)$ 的大小，并说明理由。

## 🚀 四、 同类题型海量进阶

**【变式 1】**
已知函数 $f(x) = x e^{-x}$。
（1）求 $f(x)$ 的单调区间和极值；
（2）若 $x_1 \neq x_2$，且 $f(x_1) = f(x_2)$，证明：$x_1 + x_2 > 2$。

<br><br><br><br><br><br><br><br>

**【变式 2】**
已知函数 $f(x) = \frac{\ln x}{x}$。
若 $x_1, x_2$ 是 $f(x) = m$ 的两个不同实根，证明：$x_1 x_2 > e^2$。

<br><br><br><br><br><br><br><br>

**【变式 3】**
已知函数 $f(x) = x - a \ln x \ (a>0)$。
（1）若 $f(x)$ 存在两个零点 $x_1, x_2 \ (x_1 < x_2)$，求 $a$ 的取值范围；
（2）在（1）的条件下，证明：$x_1 + x_2 > 2a$。

<br><br><br><br><br><br><br><br>

**【变式 4】**
已知函数 $f(x) = e^x - ax \ (a>0)$。
（1）若 $f(x)$ 有两个零点 $x_1, x_2 \ (x_1 < x_2)$，求 $a$ 的取值范围；
（2）在（1）的条件下，证明：$x_1 + x_2 > 2$。

<br><br><br><br><br><br><br><br>

**【变式 5】**
已知函数 $f(x) = e^x - ax - 2$。
（1）当 $a = 1$ 时，求曲线 $y=f(x)$ 在点 $(0, f(0))$ 处的切线方程；
（2）若 $f(x)$ 有两个零点 $x_1, x_2$，证明：$x_1 + x_2 < 2\ln a$。

<br><br><br><br><br><br><br><br>

**【变式 6】**
已知函数 $f(x) = (x-2)e^x + a(x-1)^2 \ (a>0)$。
（1）讨论 $f(x)$ 的单调性；
（2）若 $f(x)$ 有两个零点 $x_1, x_2$，证明：$x_1 + x_2 < 0$。
