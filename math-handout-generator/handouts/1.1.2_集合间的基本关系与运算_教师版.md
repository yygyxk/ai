## 一、 知识精讲与深度剖析

### 1. 集合间的基本关系
- **子集**：如果集合 $A$ 的**任意一个元素**都是集合 $B$ 的元素，就说 $A$ 是 $B$ 的子集，记作 $A \subseteq B$ 或 $B \supseteq A$。
- **真子集**：如果集合 $A \subseteq B$，但存在元素 $x \in B$ 且 $x \notin A$，就说 $A$ 是 $B$ 的真子集，记作 $A \subsetneqq B$。
- **相等**：若 $A \subseteq B$ 且 $B \subseteq A$，则 $A = B$。
- **空集**：不含任何元素的集合，记作 $\emptyset$。
  - **核心铁律**：空集是**任何集合**的子集（$\emptyset \subseteq A$），是任何**非空集合**的真子集（$\emptyset \subsetneqq A$）。

### 2. 子集个数定理（极高频必考）
对于含有 $n$ 个元素的有限集 $A = \{a_1, a_2, \dots, a_n\}$：
- 它的**子集**个数共有 **$2^n$** 个。
- 它的**真子集**个数共有 **$2^n - 1$** 个（去除了它本身）。
- 它的**非空真子集**个数共有 **$2^n - 2$** 个（去除了它本身和空集 $\emptyset$）。

### 3. 集合的基本运算
- **交集**：由所有属于 $A$ **且**属于 $B$ 的元素构成的集合。记作 $A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$。
- **并集**：由所有属于 $A$ **或**属于 $B$ 的元素构成的集合。记作 $A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$。
- **全集与补集**：若一个集合包含了我们所研究问题中涉及的所有元素，称之为全集 $U$。集合 $A$ 的补集记作 $\complement_{U}{A} = \{x \mid x \in U \text{ 且 } x \notin A\}$。
- **【教材帮深度拓展：德·摩根定律（反演律）】**
  - $\complement_{U}{(A \cup B)} = (\complement_{U}{A}) \cap (\complement_{U}{B})$
  - $\complement_{U}{(A \cap B)} = (\complement_{U}{A}) \cup (\complement_{U}{B})$
  - *口诀：补集去括号，交并互换。*

## 三、 核心题型与精选变式

### 题型一：集合关系与子集个数公式的应用
**【典例1】**
已知集合 $A = \{x \in \mathbb{N} \mid x \le 3\}$，则集合 $A$ 的真子集个数为（   ）
A. 16     B. 15     C. 8     D. 7

- **【思路点拨】** 先用列举法求出集合元素的个数 $n$，再套用 $2^n-1$ 公式。注意 $x \in \mathbb{N}$ 包含 $0$。
- **【规范解答】** $A = \{0, 1, 2, 3\}$，共有 $n=4$ 个元素。其真子集个数为 $2^4 - 1 = 15$ 个。故选 B。

**【阶梯变式 1-1】**
若集合 $M$ 满足 $\{1, 2\} \subseteq M \subsetneqq \{1, 2, 3, 4, 5\}$，则满足条件的集合 $M$ 的个数为 ________。
**【解析】** $M$ 必须包含 $1, 2$，且剩下的元素可从 $\{3, 4, 5\}$ 中选取。由于 $M$ 是真子集，所以不能全选。从 3 个元素中选子集有 $2^3 = 8$ 种，排除全选的 1 种情况（即等于全集），共有 $8 - 1 = 7$ 种。

**【阶梯变式 1-2】**
已知集合 $A = \{x \mid x^2 - 3x + 2 = 0\}$，$B = \{1, 2, 3, 4\}$，写出所有满足 $A \subseteq X \subseteq B$ 的集合 $X$。
**【解析】** $A = \{1, 2\}$。因为 $A \subseteq X \subseteq B$，所以 $X$ 必含 1,2，可能含 3,4。所以 $X$ 可以是 $\{1,2\}, \{1,2,3\}, \{1,2,4\}, \{1,2,3,4\}$。

**【阶梯变式 1-3】**
非空集合 $A$ 满足：若 $x \in A$，则 $5-x \in A$。若 $A \subseteq \{1, 2, 3, 4\}$，则满足条件的集合 $A$ 的个数为 ________。
**【解析】** 由题意，若 $1 \in A$，则 $4 \in A$；若 $2 \in A$，则 $3 \in A$。所以元素 $1, 4$ 必须成对出现，元素 $2, 3$ 必须成对出现。将它们打包为两个“组合元素”：$\{1,4\}$ 和 $\{2,3\}$。集合 $A$ 可由这两个“组合元素”构成。非空子集个数为 $2^2 - 1 = 3$ 个，分别是 $\{1,4\}, \{2,3\}, \{1,2,3,4\}$。

### 题型二：【超级防雷重点】利用子集关系求参数
**【典例2】**
已知集合 $A = \{x \mid -2 \le x \le 5\}$，集合 $B = \{x \mid m+1 \le x \le 2m-1\}$。若 $B \subseteq A$，求实数 $m$ 的取值范围。

- **【思路点拨】** **做这种题，先问自己：$B$ 可以为空集吗？** 如果可以，必须先讨论 $\emptyset$ 的情况。
- **【规范解答】**
  1) 当 $B = \emptyset$ 时，满足 $B \subseteq A$。此时 $m+1 > 2m-1 \Rightarrow m < 2$。
  2) 当 $B \neq \emptyset$ 时，需满足：
     $\begin{cases} m+1 \le 2m-1 \\ m+1 \ge -2 \\ 2m-1 \le 5 \end{cases}$
     解得 $2 \le m \le 3$。
  综上，实数 $m$ 的取值范围是 $(-\infty, 3]$。

**【阶梯变式 2-1】**
已知 $A = \{x \mid x < -1 \text{ 或 } x > 3\}$，$B = \{x \mid a \le x \le a+2\}$。若 $A \cap B = \emptyset$，求 $a$。
**【解析】** 注意 $A \cap B = \emptyset \Leftrightarrow B \subseteq \complement_{\mathbb{R}}{A}$。即 $B \subseteq [-1, 3]$。由于 $a \le a+2$ 恒成立，$B \neq \emptyset$。列不等式组 $a \ge -1$ 且 $a+2 \le 3$。解得 $-1 \le a \le 1$。

**【阶梯变式 2-2】**
集合 $A = \{x \mid x^2 - x - 2 = 0\}$，$B = \{x \mid ax = 1\}$，若 $B \subseteq A$，求 $a$ 的取值集合。
**【解析】** $A = \{-1, 2\}$。
若 $B = \emptyset$，则 $a=0$。此时 $B \subseteq A$ 成立。
若 $B \neq \emptyset$，则 $x = \frac{1}{a} \in A$。所以 $\frac{1}{a} = -1 \Rightarrow a = -1$；或 $\frac{1}{a} = 2 \Rightarrow a = \frac{1}{2}$。
综上，$a \in \{0, -1, \frac{1}{2}\}$。

**【阶梯变式 2-3】**
设 $A = \{x \mid x^2 - 4x + 3 < 0\}$，$B = \{x \mid x^2 - 2ax + a^2 - 1 \le 0\}$，且 $A \cup B = B$，求 $a$。
**【解析】** $A \cup B = B \Leftrightarrow A \subseteq B$。
$A = (1, 3)$。$B$ 对应的方程根为 $(a-1)(a+1)=0$，即 $B = [a-1, a+1]$。
要使 $(1, 3) \subseteq [a-1, a+1]$，必须有 $a-1 \le 1$ 且 $a+1 \ge 3$。
解得 $a \le 2$ 且 $a \ge 2$，所以 $a = 2$。

### 题型三：集合的交、并、补综合运算
**【典例3】**
已知集合 $M = \{x \mid x+2 \ge 0\}$，$N = \{x \mid x-1 < 0\}$，则 $M \cap N =$ （   ）
A. $\{x \mid -2 \le x < 1\}$     B. $\{x \mid -2 < x \le 1\}$
C. $\{x \mid x \ge -2\}$        D. $\{x \mid x < 1\}$

- **【思路点拨】** 分别解出两集合的不等式，画数轴找重叠部分。
- **【规范解答】** $M = \{x \mid x \ge -2\}$，$N = \{x \mid x < 1\}$。画出数轴，两者的公共部分为 $[-2, 1)$。故选 A。

**【阶梯变式 3-1】**
已知集合 $A = \{x \mid -1 < x < 2\}$，$B = \{x \mid 0 \le x \le 3\}$，则 $A \cup B =$ （   ）
**【解析】** $A \cup B$ 取两者所有覆盖区域，即 $(-1, 3]$。

**【阶梯变式 3-2】**
设全集 $U = \mathbb{R}$，$A = \{x \mid x^2 > 4\}$，则 $\complement_{U}{A} =$ ________。
**【解析】** $A = \{x \mid x > 2 \text{ 或 } x < -2\}$。其补集为 $[-2, 2]$。

**【阶梯变式 3-3】**
已知全集 $U=\{1, 2, 3, 4, 5\}$，集合 $A=\{1, 3\}$，集合 $B=\{3, 4, 5\}$，则 $(\complement_{U}{A}) \cap B =$ ________。
**【解析】** $\complement_{U}{A} = \{2, 4, 5\}$，再与 $B$ 求交集得 $\{4, 5\}$。

## 四、 当堂过关检测

### 【A组·基础限时秒杀】
1. 已知集合 $A = \{0, 1, 2\}$ 的真子集个数为 ________。
   **【解答】** $2^3 - 1 = 7$。
2. 全集 $U = \{1, 2, 3, 4, 5, 6\}$，$M = \{1, 2, 4\}$，$N = \{2, 3, 5\}$，则 $\complement_{U}{(M \cup N)} =$ ________。
   **【解答】** $M \cup N = \{1, 2, 3, 4, 5\}$，补集为 $\{6\}$。
3. 若 $A = \{x \mid x \ge 2\}$，$B = \{x \mid x < 3\}$，求 $\complement_{\mathbb{R}}{(A \cap B)}$。
   **【解答】** $A \cap B = [2, 3)$，其补集为 $(-\infty, 2) \cup [3, +\infty)$。

### 【B组·中等综合提升】
4. 已知集合 $A = \{1, 3, m\}$，$B = \{1, m\}$，且 $A \cup B = A$，则 $m =$ ________。
   **【解答】** $A \cup B = A \Leftrightarrow B \subseteq A$。显然 $m \in A$，所以只要 $m \neq 1, 3$ 且满足互异性即可。即 $m \in \mathbb{R}$ 且 $m \neq 1, 3$。
5. 设集合 $A = \{x \mid x^2 - x = 0\}$，$B = \{x \mid ax = 2\}$，若 $A \cap B = B$，求 $a$。
   **【解答】** $A \cap B = B \Leftrightarrow B \subseteq A$。$A = \{0, 1\}$。若 $B = \emptyset$，$a=0$ 满足；若 $B \neq \emptyset$，则 $2/a \in \{0, 1\}$，显然 $2/a \neq 0$，所以 $2/a = 1 \Rightarrow a = 2$。故 $a = 0$ 或 $a = 2$。
6. 已知 $A = \{x \mid -1 \le x < 3\}$，$B = \{x \mid 2x - 4 \ge x - 2\}$，求 $A \cap B$。
   **【解答】** 解 $B$ 得 $x \ge 2$。$A \cap B = [2, 3)$。

### 【C组·拔高压轴挑战】
7. 设集合 $A = \{x \mid -1 \le x \le 2\}$，$B = \{x \mid x^2 - (2a+1)x + a(a+1) \le 0\}$。若 $A \subseteq B$，求 $a$ 的取值范围。
   **【解答】** $B$ 的方程分解为 $(x-a)[x-(a+1)] \le 0$，所以 $B = [a, a+1]$。要使 $[-1, 2] \subseteq [a, a+1]$，必须 $a \le -1$ 且 $a+1 \ge 2$，即 $a \le -1$ 且 $a \ge 1$，这不可能！所以无解，即 $a$ 的范围是 $\emptyset$。
8. 某班有 50 名学生，其中有 30 人喜欢篮球，25 人喜欢足球，10 人两样都不喜欢。问两样都喜欢的人有多少？
   **【解答】** 利用容斥原理。全集 50 人，两样都不喜欢 10 人，说明喜欢篮球或足球的（并集）有 40 人。$|A \cup B| = |A| + |B| - |A \cap B|$，所以 $40 = 30 + 25 - x$，解得 $x = 15$。

## 五、 易错坑点防雷

- 🧨 **易错点1**：看到 $A \subseteq B$，直接就去列不等式组，彻底忘记空集。
  **正确做法**：把这六个字刻在脑子里：**“空集是任意集合的子集”**。凡是带有参数的集合 $A \subseteq B$，$A$ 都有可能为空！第一步必须写出“当 $A = \emptyset$ 时...”。这是出题人最喜欢的钓鱼手法，没有之一。
- 🧨 **易错点2**：求补集时忘记端点（实心点与空心圈）。
  **正确做法**：画数轴！原集合是实心点，它的补集一定是空心圈；原集合是空心圈，补集必定是实心点（$\ge$ 变 $<$，$>$ 变 $\le$）。
