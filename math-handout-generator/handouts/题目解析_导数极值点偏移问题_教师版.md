# 🧑‍🏫 导数极值点偏移问题 题型深度解构

## 💡 一、 命题密码解析与核心知识点总结
- **核心概念透析（什么是极值点偏移？）**：
  对于函数 $f(x)$，若其在某区间内存在唯一极值点 $x_0$。当 $f(x_1) = f(x_2)$（且 $x_1 \neq x_2$）时，如果函数的图象关于直线 $x = x_0$ 完美对称，那么必然有这两个点的中点 $\frac{x_1+x_2}{2} = x_0$。
  但如果函数图象是不对称的（例如受指数函数 $e^x$ 或对数函数 $\ln x$ 的影响，导致图象一侧平缓，另一侧陡峭），那么要在两侧找到高度相同的点，平缓一侧的自变量要走的距离必然大于陡峭一侧的距离。这就导致了这两个点的中点 $\frac{x_1+x_2}{2}$ 偏离了原来的极值点 $x_0$。这就是极值点偏移的几何本质。
  > **🗣️ 教师授课引导思路（概念导入）：**
  > “同学们，讲极值点偏移前，大家伸出两只手，想象一个完美的二次函数抛物线，极值点在中间 $x_0$，两边一样高的地方 $x_1, x_2$，它们的中点肯定恰好落在 $x_0$ 上。对吧？但如果右边被指数函数 $e^x$ 往上猛拉了一把，变得非常陡峭，左边相对平缓。这时候要在两边找同样高度的点，陡峭的那边是不是只需要走一点点距离？平缓的那边要走很远？这就导致它们的中点‘跑偏’了，这就是极值点偏移的最直观几何意义！”
- **考查知识点**：导数在函数单调性中的应用、双变量极值点偏移的代数证明方法（对称性构造法、对数均值不等式、比值换元法）。
- **高考占比与频次**：近 5 年高考全国卷及各地名校模拟卷压轴题绝对核心热点，常设在解答题第二问，分值占比 6~8 分。
- **常见命题形式与变体**：
  1. **和差型**：证明 $x_1+x_2 > 2x_0$ 或 $x_1+x_2 < 2x_0$（或相减等）。
  2. **积商型**：证明 $x_1 x_2 > x_0^2$ 或 $x_1 x_2 < x_0^2$。

## 🚧 二、 破题核心通法与易错防雷

- **解题通法（三大SOP模型）**：
  1. **【最核心通法：对称构造法】**
     当题目要求证明 $x_1+x_2 > 2x_0$ 时（假设 $x_1 < x_0 < x_2$），等价于证明 $x_2 > 2x_0 - x_1$。
     利用函数在极值点右侧的单调性，把自变量的大小比较，**转化为函数值的大小比较**，即证明 $f(x_2)$ 与 $f(2x_0-x_1)$ 的关系。
     由于已知 $f(x_1) = f(x_2)$，最终转化为证明 $f(x_1)$ 与 $f(2x_0-x_1)$ 的大小关系。
     **标准操作程序（SOP）**：构造一元辅助函数 $g(x) = f(x) - f(2x_0-x)$，求导判断单调性，代入极值点得出符号，从而证毕。
     > **🗣️ 教师授课引导思路（通法总结）：**
     > “记住，遇到 $f(x_1)=f(x_2)$ 让你证明 $x_1+x_2 > c$ 的，**绝对不要去硬解方程**！方程含有超越函数是解不出来的！我们的核心战术只有四个字：‘**对称构造**’！把双变量变成单变量，把证明自变量的大小关系，转化为证明函数值的大小关系。这是数学上的降维打击！”
  2. **【对数均值法】**
     当原函数中包含复杂的指数运算，直接构造相减求导过于复杂时，考虑对 $f(x_1) = f(x_2)$ 两边同时取对数，将乘除运算降级为加减运算，再进行构造。
  3. **【比值换元法】**
     当出现齐次式或积商型偏移时，常令 $t = \frac{x_1}{x_2}$（设 $t > 1$），利用原方程消去其中一个变量，构造关于 $t$ 的单变量函数进行证明。

- **易错防雷区**：
  1. **辅助函数定义域弄错**：构造 $g(x) = f(x) - f(2x_0-x)$ 时，必须明确 $x$ 的取值范围是极值点的左侧还是右侧！如果设错左右侧，放缩不等号将完全反转。
  2. **对二次求导的畏难情绪**：偏移问题构造的新函数 $g(x)$，其一阶导数往往无法直接判断出正负号，必须坚定信念进行二次甚至三次求导！
  3. **忽略题目隐藏边界**：题目有时会附加如 $0<x_1<2$ 的条件，放缩时若没有卡紧这个边界区间，二次求导时会丢失极值判定依据。

## 📖 三、 经典原题精讲精析

**【原题】**
已知函数 $f(x) = \frac{x^2}{e^{ax}}$，其中 $a>0$。
（1）若 $f(x)$ 在 $(0,2]$ 上单调递增，求 $a$ 的取值范围；
（2）当 $a=1$ 时，若 $x_1+x_2=4$ 且 $0<x_1<2$，判断 $f(x_1)$ 与 $f(x_2)$ 的大小，并说明理由。

> **🗣️ 教师授课引导思路：**
> - **切入点**：“同学们，看到第二问 $x_1+x_2=4$ 和 $0<x_1<2$，咱们在坐标系里想象一下，这是在暗示关于哪条直线对称？（$x=2$）如果是完全对称的抛物线，这两个点的函数值应该相等。但现在分母是个指数函数，它增长极快，一定会把原有的对称性‘拉扯’偏移！”
> - **思维脚手架**：“既然知道图象偏移了，怎么严谨比较大小？直接把 $x_1$ 和 $4-x_1$ 代进去算 $e$ 的次幂太恶心了。为了干掉讨厌的指数，我们往往想到什么运算？（取对数！）所以，我们不妨比较 $\ln f(x_1)$ 和 $\ln f(4-x_1)$，这样就把乘除变成了加减！”

**【规范解答】**
（1）$f'(x) = \frac{x(2-ax)}{e^{ax}}$。
因为 $f(x)$ 在 $(0, 2]$ 上单调递增，所以 $f'(x) \geqslant 0$ 对 $\forall x \in (0, 2]$ 恒成立。
即 $ax \leqslant 2$ 对 $\forall x \in (0, 2]$ 恒成立，所以 $a \leqslant \frac{2}{x}$ 的最小值，即 $a \leqslant 1$。
又已知 $a > 0$，故 $a$ 的取值范围是 $(0, 1]$。

（2）当 $a=1$ 时，$f(x) = \frac{x^2}{e^x}$，$x \in (0,2)$ 时递增，$(2,+\infty)$ 时递减。
要比较 $f(x_1)$ 与 $f(x_2)$，即比较 $f(x_1)$ 与 $f(4-x_1)$。
构造函数 $g(x) = \frac{f(x)}{f(4-x)} = \left(\frac{x}{4-x}\right)^2 e^{4-2x}$，其中 $x \in (0, 2)$。
两边取对数，令 $h(x) = \ln g(x) = 2\ln x - 2\ln(4-x) + 4 - 2x$。
求导：$h'(x) = \frac{2}{x} + \frac{2}{4-x} - 2 = \frac{8}{x(4-x)} - 2$。
因为 $x \in (0, 2)$，所以 $x(4-x) < \left(\frac{x+4-x}{2}\right)^2 = 4$。
所以 $h'(x) > \frac{8}{4} - 2 = 0$，即 $h(x)$ 在 $(0, 2)$ 上单调递增。
所以 $h(x) < h(2) = 0$。即 $\ln g(x) < 0 \implies g(x) < 1$。
所以 $f(x_1) < f(4-x_1) = f(x_2)$。综上，$f(x_1) < f(x_2)$。

## 🔥 四、 同类题型进阶拓展与解析

**【变式 1】（基础热身题）**
已知函数 $f(x) = x e^{-x}$。若 $x_1 \neq x_2$，且 $f(x_1) = f(x_2)$，证明：$x_1 + x_2 > 2$。

> **🎯 设坑点/考查侧重点：** 最基础的极值点偏移“和差型”证明。重点训练构造 $F(x) = f(x) - f(2-x)$ 的定式思维。

**【精析】**
不妨设 $x_1 < x_2$。求导易知 $f(x)$ 极值点为 $x=1$，故 $x_1 < 1 < x_2$。
要证 $x_1 + x_2 > 2$，即证 $x_2 > 2 - x_1$。
因为 $x_1 < 1 \implies 2-x_1 > 1$，且 $f(x)$ 在 $(1, +\infty)$ 递减，
只需证 $f(x_2) < f(2-x_1)$，即证 $f(x_1) < f(2-x_1)$。
构造 $g(x) = f(x) - f(2-x) \ (x<1)$，求导得 $g'(x) = (1-x)(e^{-x} - e^{x-2}) > 0$。
$g(x)$ 递增，$g(x) < g(1) = 0$，所以 $f(x) < f(2-x)$。得证。

**【变式 2】（积商型基础题）**
已知函数 $f(x) = \frac{\ln x}{x}$。若 $x_1, x_2$ 是 $f(x) = m$ 的两个不同实根，证明：$x_1 x_2 > e^2$。

> **🎯 设坑点/考查侧重点：** 积商型偏移问题。引导学生类比变式 1，把“和”大于2 变为“积”大于 $e^2$。只需构造 $F(x) = f(x) - f(\frac{e^2}{x})$。

**【精析】**
$f(x)$ 极值点为 $x=e$。设 $0 < x_1 < e < x_2$。
要证 $x_1 x_2 > e^2 \iff x_2 > \frac{e^2}{x_1}$。只需证 $f(x_2) < f(\frac{e^2}{x_1}) \iff f(x_1) < f(\frac{e^2}{x_1})$。
构造 $g(x) = f(x) - f(\frac{e^2}{x}) = \frac{\ln x}{x} - \frac{x(2-\ln x)}{e^2} \ (0 < x < e)$。求导即可证 $g(x) < 0$。得证。

**【变式 3】（2020·新高考II卷改编）**
已知函数 $f(x) = x - a \ln x \ (a>0)$。若 $f(x)$ 存在两个零点 $x_1, x_2 \ (x_1 < x_2)$，证明：$x_1 + x_2 > 2a$。

> **🎯 设坑点/考查侧重点：** 带有参数的偏移问题，考察参数消元与代换。

**【精析】**
$f'(x) = 1 - \frac{a}{x}$，极值点 $x=a$。故 $x_1 < a < x_2$。
同理转证 $f(x_1) > f(2a-x_1)$（注意此处由于是求零点，需特别注意开闭区间单调性方向）。
构造 $g(x) = f(x) - f(2a-x) = 2x - 2a - a\ln x + a\ln(2a-x) \ (0 < x < a)$。
$g'(x) = 2 - \frac{a}{x} - \frac{a}{2a-x} = \frac{-2(x-a)^2}{x(2a-x)} < 0$。
所以 $g(x)$ 递减，$g(x) > g(a) = 0 \implies f(x) > f(2a-x)$。得证。

**【变式 4】（2013·湖南卷理科压轴题）**
已知函数 $f(x) = e^x - ax \ (a>0)$。
（1）若 $f(x)$ 有两个零点 $x_1, x_2 \ (x_1 < x_2)$，求 $a$ 的取值范围；
（2）在（1）的条件下，证明：$x_1 + x_2 > 2$。

> **🎯 设坑点/考查侧重点：** 经典的高考压轴题，极值点偏移的母题之一。引导学生发现极值点偏移的本质，当无法直接构造 $f(x) - f(2-x)$ 时，需要分离参数转化为 $h(x) = \frac{e^x}{x} = a$，进而转变为定点（$x=1$）偏移模型。

**【精析】**
（1）$f'(x) = e^x - a$。令 $f'(x)=0$ 得极小值点 $x = \ln a$。
要有两个零点，必须有 $f(\ln a) = a - a\ln a < 0 \implies \ln a > 1 \implies a > e$。同时结合 $x \to \pm \infty$ 极限可得 $a > e$。
（2）证明：由 $f(x_1)=f(x_2)=0$，得 $a = \frac{e^{x_1}}{x_1} = \frac{e^{x_2}}{x_2}$。
令 $h(x) = \frac{e^x}{x}$，则 $h'(x) = \frac{e^x(x-1)}{x^2}$。可知 $h(x)$ 在 $x=1$ 处取得极小值 $e$。
要证 $x_1 + x_2 > 2$，即证 $x_2 > 2 - x_1$。由于 $x_1 < 1 < x_2$，$h(x)$ 在 $(1, +\infty)$ 递增，
只需证 $h(x_2) > h(2-x_1)$，即证 $h(x_1) > h(2-x_1)$。
构造 $G(x) = h(x) - h(2-x) \ (0 < x < 1)$，求导即可证得 $G(x) > 0$，从而得证。

**【变式 5】（2020·新高考I卷山东压轴题）**
已知函数 $f(x) = e^x - ax - 2$。
（1）当 $a = 1$ 时，求曲线 $y=f(x)$ 在点 $(0, f(0))$ 处的切线方程；
（2）若 $f(x)$ 有两个零点 $x_1, x_2$，证明：$x_1 + x_2 < 2\ln a$。

> **🎯 设坑点/考查侧重点：** 包含参数 $a$ 且偏移中心随 $a$ 变动（$x_0 = \ln a$）。考查学生如何构造含有参数的对称函数 $F(x) = f(x) - f(2\ln a - x)$ 并利用原方程消去参数 $a$ 的硬核代数变形能力。

**【精析】**
（1）求导：$f'(x) = e^x - 1$。
代入 $x=0$，得切点纵坐标 $f(0) = e^0 - 0 - 2 = -1$。
切线斜率 $k = f'(0) = e^0 - 1 = 0$。
所以切线方程为 $y - (-1) = 0 \cdot (x - 0)$，即 $y = -1$。

（2）证明：
> **🗣️ 课堂互动/引导：** “同学们，题目要我们证明 $x_1+x_2 < 2\ln a$，第一步是不是应该先搞清楚函数图象长什么样？所以必须先求导，找到极值点在哪儿！”

$f'(x) = e^x - a$。令 $f'(x) = 0$，解得唯一的极值点 $x_0 = \ln a$。
（注：由于 $f(x)$ 有两个零点，必然有极小值小于0，且 $a>0$）。
当 $x < \ln a$ 时，$f'(x) < 0$，$f(x)$ 递减；
当 $x > \ln a$ 时，$f'(x) > 0$，$f(x)$ 递增。
不妨设 $x_1 < x_2$，由图象可知 $x_1 < \ln a < x_2$。

> **🗣️ 课堂互动/引导：** “既然极值点在 $\ln a$，$x_1, x_2$ 分布在两侧，要证 $x_1+x_2 < 2\ln a$，我们可以把它化为 $x_2 < 2\ln a - x_1$。现在 $x_2$ 和 $2\ln a - x_1$ 都在极值点 $\ln a$ 的右侧。右侧函数是单调递增的，所以要想证明自变量的大小关系，应该转化为证明什么？”

要证 $x_2 < 2\ln a - x_1$，只需证明 $f(x_2) < f(2\ln a - x_1)$ 即可。
因为 $x_2$ 是原函数零点，即 $f(x_2) = 0$。
所以我们只需要证明：**$f(2\ln a - x_1) > 0$**。

> **🗣️ 课堂互动/引导：** “把 $2\ln a - x_1$ 代入原函数，会不会变成一个很恶心的式子？我们试着代进去：$f(2\ln a - x_1) = e^{2\ln a - x_1} - a(2\ln a - x_1) - 2$。既有指数又有对数还有 $a$！怎么简化？别忘了，$x_1$ 也是零点！”

代入并化简：
$f(2\ln a - x_1) = \frac{e^{2\ln a}}{e^{x_1}} - 2a\ln a + ax_1 - 2 = \frac{a^2}{e^{x_1}} - 2a\ln a + ax_1 - 2$。
由 $f(x_1) = 0$ 得：$e^{x_1} = ax_1 + 2$。
将 $e^{x_1}$ 替换掉，并在右边提取出 $a$：
$f(2\ln a - x_1) = \frac{a^2}{ax_1+2} - 2a\ln a + ax_1 - 2$。
这样虽然参数少了些，但直接证明仍然非常繁琐。其实，极值点偏移有一套万能的**对称构造法**。

**（更巧妙的解法二）：**
构造 $F(x) = f(x) - f(2\ln a - x) \quad (x < \ln a)$。
$F'(x) = f'(x) + f'(2\ln a - x) = (e^x - a) + (e^{2\ln a - x} - a) = e^x + \frac{a^2}{e^x} - 2a$。
因为 $(e^x - a)^2 \geqslant 0$，所以 $e^x + \frac{a^2}{e^x} \geqslant 2a$（当且仅当 $e^x=a$ 即 $x=\ln a$ 取等号）。
因为 $x < \ln a$，所以 $F'(x) > 0$ 恒成立！
这意味着 $F(x)$ 在 $(-\infty, \ln a)$ 上单调递增。
所以 $F(x_1) < F(\ln a) = f(\ln a) - f(\ln a) = 0$。
即 $f(x_1) - f(2\ln a - x_1) < 0 \implies f(2\ln a - x_1) > f(x_1) = 0$。
由前面可知 $f(2\ln a - x_1) > 0 = f(x_2)$，且两者都在递增区间，故 $2\ln a - x_1 > x_2 \implies x_1+x_2 < 2\ln a$。得证！

> **🗣️ 课堂互动/引导：** “大家看，如果硬代入会算得很绝望，而换成构造 $F(x)$，求导后刚好凑成了一个完全平方式！极值点偏移问题，**对折相减法永远是你最坚实的后盾**！”

**【变式 6】（2016·全国I卷理科压轴神题）**
已知函数 $f(x) = (x-2)e^x + a(x-1)^2 \ (a>0)$。
（1）讨论 $f(x)$ 的单调性；
（2）若 $f(x)$ 有两个零点 $x_1, x_2$，证明：$x_1 + x_2 < 2$。

> **🎯 设坑点/考查侧重点：** 高考历史上的“神题”。这道题不仅考验极值点偏移的构造能力，更要求极其细腻的代数变形（利用原方程替代消元），甚至需要二次求导。

**【精析】**
（1）求导：$f'(x) = (x-1)e^x + 2a(x-1) = (x-1)(e^x + 2a)$。
> **🗣️ 课堂互动/引导：** “看到这个式子大家应该能松一口气，因为 $a>0$，所以 $e^x+2a$ 永远是大于0的，这个导数的符号完全由谁决定？（由 $x-1$ 决定！）极值点一目了然！”
所以当 $x < 1$ 时，$f'(x) < 0$；当 $x > 1$ 时，$f'(x) > 0$。
故 $f(x)$ 在 $(-\infty, 1)$ 上单调递减，在 $(1, +\infty)$ 上单调递增，极小值点为 $x=1$。

（2）证明 $x_1+x_2 < 2$。
结合第一问，既然极小值点是 $x=1$，若有两个零点，必然分布在 1 的两侧，即 $x_1 < 1 < x_2$。
为了让大家更直观地看到“偏移”，我们代入 $a=1$ 绘制了它的函数图象：

![极值点偏移示意图]images/2016_math_var6.png)

> **🗣️ 课堂互动/引导：** “由图象可知，由于指数函数 $e^x$ 在右侧的暴增属性，导致右侧曲线比左侧更加‘陡峭’。这就使得要想回落到 0（即到达 $x_2$），右侧走过的距离要比左侧小！也就是说 $|x_2 - 1| < |1 - x_1|$，这才是 $x_1+x_2 < 2$ 在图象上的本质几何意义！”

**严谨证明过程：**
要证 $x_1 + x_2 < 2$，即证 $x_2 < 2 - x_1$。
因为 $x_1 < 1$，所以 $2 - x_1 > 1$。
因为 $f(x)$ 在 $(1, +\infty)$ 单调递增，且 $x_2 > 1$。
所以要证 $x_2 < 2-x_1$，只需证明：$f(x_2) < f(2-x_1)$。
又因为 $f(x_2) = 0$（它是零点），所以我们只需证明：**$f(2-x_1) > 0$**。

> **🗣️ 课堂互动/引导：** “好，目标明确了。现在请大家把 $2-x_1$ 毫不犹豫地代入原函数 $f(x)$ 中。代入后怎么处理里面的参数 $a$ 呢？”

代入得：$f(2-x_1) = (2-x_1-2)e^{2-x_1} + a(2-x_1-1)^2 = -x_1 e^{2-x_1} + a(1-x_1)^2$。
又因为 $x_1$ 是零点，所以 $f(x_1) = (x_1-2)e^{x_1} + a(x_1-1)^2 = 0$。
将方程整理一下，因为我们要证明的式子里有 $a(1-x_1)^2$，我们把它整体替换掉：
$a(1-x_1)^2 = (2-x_1)e^{x_1}$。

把这个整体代入我们要证的式子：
$f(2-x_1) = -x_1 e^{2-x_1} + (2-x_1)e^{x_1}$
提取公因式 $e^{x_1}$，得到：
$f(2-x_1) = e^{x_1} \left[ -x_1 e^{2-2x_1} + 2 - x_1 \right]$。

> **🗣️ 课堂互动/引导：** “因为外面的 $e^{x_1} > 0$，所以能不能证出来，全看中括号里面那一坨了。但那坨看着很乱，我们可不可以做个简单的换元，让式子看起来清爽一点？比如令 $t = 1-x_1$？”

由于 $x_1 < 1$，令 $t = 1-x_1$，则 $t > 0$。此时 $x_1 = 1-t$，$2-x_1 = 1+t$，$2-2x_1 = 2t$。
括号里的式子变为：
$M(t) = -(1-t)e^{2t} + (1+t)$。
现在问题转化为：**证明当 $t > 0$ 时，$M(t) > 0$**。

这是一个关于 $t$ 的新函数，果断求导！
$M'(t) = - [ (-1)e^{2t} + (1-t) \cdot 2e^{2t} ] + 1 = 1 - (1-2t)e^{2t}$。
看不出符号？别慌，遇到指数复合，勇敢进行二次求导！
$M''(t) = - [ (-2)e^{2t} + (1-2t) \cdot 2e^{2t} ] = - [ -2t \cdot 2e^{2t} ] = 4t e^{2t}$。
因为 $t > 0$，显然 $4t e^{2t} > 0$！
所以一阶导函数 $M'(t)$ 在 $(0, +\infty)$ 上是单调递增的！
所以 $M'(t) > M'(0) = 1 - 1 = 0$。
既然 $M'(t) > 0$，那么原函数 $M(t)$ 在 $(0, +\infty)$ 也是单调递增的！
所以 $M(t) > M(0) = -1 \cdot 1 + 1 = 0$。
证毕！！（$M(t) > 0 \implies f(2-x_1) > 0 \implies x_1+x_2 < 2$）
