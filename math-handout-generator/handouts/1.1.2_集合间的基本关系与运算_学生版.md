## 一、 知识精讲与深度剖析

### 1. 集合间的基本关系
- **子集**：如果集合 $A$ 的________都是集合 $B$ 的元素，就说 $A$ 是 $B$ 的子集，记作 $A \subseteq B$ 或 $B \supseteq A$。
- **真子集**：如果集合 $A \subseteq B$，但存在元素 $x \in B$ 且 $x \notin A$，就说 $A$ 是 $B$ 的真子集，记作 $A \subsetneqq B$。
- **相等**：若 $A \subseteq B$ 且 $B \subseteq A$，则 $A = B$。
- **空集**：不含任何元素的集合，记作 $\emptyset$。
  - **核心铁律**：空集是________的子集（$\emptyset \subseteq A$），是任何________的真子集（$\emptyset \subsetneqq A$）。

### 2. 子集个数定理（极高频必考）
对于含有 $n$ 个元素的有限集 $A = \{a_1, a_2, \dots, a_n\}$：
- 它的**子集**个数共有 ________ 个。
- 它的**真子集**个数共有 ________ 个（去除了它本身）。
- 它的**非空真子集**个数共有 ________ 个（去除了它本身和空集 $\emptyset$）。

### 3. 集合的基本运算
- **交集**：由所有属于 $A$ ________属于 $B$ 的元素构成的集合。记作 $A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$。
- **并集**：由所有属于 $A$ ________属于 $B$ 的元素构成的集合。记作 $A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$。
- **全集与补集**：若一个集合包含了我们所研究问题中涉及的所有元素，称之为全集 $U$。集合 $A$ 的补集记作 $\complement_{U}{A} = \{x \mid x \in U \text{ 且 } x \notin A\}$。
- **【教材帮深度拓展：德·摩根定律（反演律）】**
  - $\complement_{U}{(A \cup B)} = (\complement_{U}{A}) \cap (\complement_{U}{B})$
  - $\complement_{U}{(A \cap B)} = (\complement_{U}{A}) \cup (\complement_{U}{B})$
  - *口诀：补集去括号，交并互换。*
