# 1.1.1 集合的概念与表示 - 教师版

> **💡 趣味引入 / 生活类比**
> 教师引导：“我们常说‘物以类聚，人以群分’。在数学中，把具有某种相同属性的事物放在一起，就成了一个‘集合’。比如‘咱们班戴眼镜的同学’能构成一个集合。但如果是‘咱们班长得帅的同学’，能算集合吗？今天我们就来用极其严谨的数学眼光，看看‘圈子’到底是怎么划分的。”

## 一、 知识精讲与深度剖析

### 1. 集合与元素的核心概念
- **集合的定义**：一般地，把一些能够**确切指定**的对象看作一个整体，就说这个整体是由这些对象的全体构成的集合（或简称集）。
- **元素的定义**：构成集合的每个对象叫做这个集合的元素。
- **集合中元素的三个特征**（**高考必考点，解题破局核心**）：
  - **确定性**：一个对象是否属于某个集合是明确的。“高个子”、“著名数学家”、“很大的实数”不能构成集合，因为没有确切标准。
  - **互异性**：同一个集合中的元素是互不相同的。即集合中不能出现重复元素。（**核心！解含参方程求出参数后，最后一步必须用来检验！**）
  - **无序性**：集合中的元素没有先后顺序。$\{1, 2\}$ 和 $\{2, 1\}$ 表示同一个集合。

### 2. 元素与集合的关系
- **属于**：如果 $a$ 是集合 $A$ 的元素，记作 $a \in A$。
- **不属于**：如果 $a$ 不是集合 $A$ 的元素，记作 $a \notin A$。

### 3. 集合的表示方法
- **列举法**：把集合的元素一一列举出来，并用花括号 `{}` 括起来。如：$\{1, 2, 3\}$。适用于有限集或有明显规律的无限集。
- **描述法**：$\{x \in I \mid P(x)\}$。
- **【教材帮深度拓展】代表元素的“剥离本质”**（极易错！）：
  - 描述法 $\{x \mid P(x)\}$ 竖线前面的字母代表了该集合的**元素本体**。
  - $A = \{x \mid y = x^2+1\}$：代表元素是 $x$，本质是求函数定义域，即 $A = \mathbb{R}$。
  - $B = \{y \mid y = x^2+1\}$：代表元素是 $y$，本质是求函数值域，即 $B = \{y \mid y \ge 1\}$。
  - $C = \{(x,y) \mid y = x^2+1\}$：代表元素是点 $(x,y)$，本质是抛物线上的点集。

## 二、 必背符号与性质

| 概念 | 符号表示 | 意义 / 备注 |
|:---|:---:|:---|
| **自然数集** | $\mathbb{N}$ | 包含 $0, 1, 2, \dots$ |
| **正整数集** | $\mathbb{N}^{*}$ 或 $\mathbb{N}_{+}$ | 不包含 $0$，即 $1, 2, 3, \dots$ |
| **整数集** | $\mathbb{Z}$ | 包含正整数、负整数和 $0$ |
| **有理数集** | $\mathbb{Q}$ | 能表示为分数（整数之比）的数 |
| **实数集** | $\mathbb{R}$ | 所有有理数和无理数的集合 |

## 三、 北京高考命题考情速递

- **常考位置**：作为高中数学的“底层语言”，不单独出大题，常隐蔽在选择题前3题的背景中。
- **平均分值**：$0-5$ 分（作为选项辨析）。
- **核心考查形式**：
  - 结合方程的根、不等式的解集考查元素的“互异性”（如 2018 年北京卷）。
  - 利用“代表元素”的不同设置陷阱，如数列点集与函数图象点集的交汇（2022 年北京卷背景）。

## 四、 核心题型与精选变式

### 题型一：集合概念的辨析
**【典例1】**
下列各组对象能构成集合的是（   ）
A. 所有很大的实数
B. 某校高一年级视力较差的学生
C. 接近 0 的数
D. 方程 $x^2 - 2x + 1 = 0$ 的所有实数根

- **【思路点拨】** 紧扣集合元素的“确定性”。形容词“大、较差、接近”通常没有绝对标准。
- **【规范解答】** A、B、C 选项中的标准均不明确，不满足确定性，不能构成集合。D 选项方程的实数根是确定的，解为 $x=1$，可以构成集合 $\{1\}$。故选 D。

**【阶梯变式 1-1】**
下列说法正确的是（   ）
A. 集合 $\{1, 2, 2, 3\}$ 共有 4 个元素
B. 由数字 $1, 3, 5$ 组成的集合与由数字 $5, 1, 3$ 组成的集合是同一个集合
C. 所有的无理数不能构成集合
**【解析】** B。A违背互异性，应只有3个元素；B满足无序性，正确；C无理数能构成集合。

**【阶梯变式 1-2】**
以方程 $x^2-5x+6=0$ 和方程 $x^2-x-2=0$ 的解为元素构成集合 $M$，则 $M$ 中元素的个数为（   ）
A. 1     B. 2     C. 3     D. 4
**【解析】** C。前一个方程解为 $x=2$ 或 $x=3$，后一个方程解为 $x=2$ 或 $x=-1$。由元素的互异性，集合 $M = \{-1, 2, 3\}$，共3个元素。

**【阶梯变式 1-3】**
已知集合 $A$ 含有三个元素 $a-3, 2a-1, a^2+4$，若 $-3 \in A$，求实数 $a$ 的值。
**【解析】** 因为 $-3 \in A$，且 $a^2+4 > 0$，所以只能是 $a-3=-3$ 或 $2a-1=-3$。
若 $a-3=-3$，则 $a=0$，此时集合元素为 $-3, -1, 4$，满足互异性，故 $a=0$。
若 $2a-1=-3$，则 $a=-1$，此时集合元素为 $-4, -3, 5$，满足互异性，故 $a=-1$。
综上，$a=0$ 或 $a=-1$。

### 题型二：列举法与描述法的相互转化
**【典例2】**
用列举法表示集合 $A = \{x \in \mathbb{N} \mid \frac{8}{x-1} \in \mathbb{Z}\}$。

- **【思路点拨】** 限制条件有两层：结果必须是整数 $\mathbb{Z}$；但 $x$ 本身必须是自然数 $\mathbb{N}$。
- **【规范解答】**
  因为 $\frac{8}{x-1} \in \mathbb{Z}$，所以 $x-1$ 必须是 $8$ 的约数，即 $x-1 \in \{-8, -4, -2, -1, 1, 2, 4, 8\}$。
  解得 $x \in \{-7, -3, -1, 0, 2, 3, 5, 9\}$。
  又因为 $x \in \mathbb{N}$，所以剔除负数，得 $x \in \{0, 2, 3, 5, 9\}$。故集合 $A = \{0, 2, 3, 5, 9\}$。

**【阶梯变式 2-1】**
将集合 $\{(x,y) \mid x+y=3, x \in \mathbb{N}, y \in \mathbb{N}\}$ 用列举法表示为 ________。
**【解析】** $\{(0,3), (1,2), (2,1), (3,0)\}$。注意数对是作为一个整体元素。

**【阶梯变式 2-2】**
集合 $B = \{x \in \mathbb{Z} \mid \frac{6}{3-x} \in \mathbb{N}\}$ 用列举法表示为 ________。
**【解析】** $\frac{6}{3-x}$ 必须是非负整数，所以 $3-x$ 只能取正约数 $1, 2, 3, 6$。解得 $x = 2, 1, 0, -3$。因为 $x \in \mathbb{Z}$ 均满足，故 $B = \{-3, 0, 1, 2\}$。

**【阶梯变式 2-3】**
已知集合 $C = \{y \mid y = x^2 - 4x + 3, x \in \{0, 1, 2, 3, 4\}\}$，用列举法表示 $C$。
**【解析】** 当 $x=0$ 时 $y=3$；$x=1$ 时 $y=0$；$x=2$ 时 $y=-1$；$x=3$ 时 $y=0$；$x=4$ 时 $y=3$。根据互异性去重，得到 $C = \{-1, 0, 3\}$。

### 题型三：代表元素的深度辨析
**【典例3】**
已知集合 $M = \{y \mid y = x^2 - 1, x \in \mathbb{R}\}$，集合 $N = \{(x,y) \mid y = x^2 - 1, x \in \mathbb{R}\}$，这两个集合相同吗？

- **【思路点拨】** 竖线前面是什么，集合装的就是什么。不要被同样的表达式骗了。
- **【规范解答】**
  不相同。集合 $M$ 的代表元素是实数 $y$，表示函数的值域，即 $M = [-1, +\infty)$。
  集合 $N$ 的代表元素是数对 $(x,y)$，表示抛物线 $y = x^2 - 1$ 上的点集。
  一个是数集，一个是点集，两者互不相干。

**【阶梯变式 3-1】**
若集合 $P = \{x \mid y = \sqrt{x-2}\}$，则 $P =$ ________。
**【解析】** 代表元素是 $x$，求定义域。由 $x-2 \ge 0$ 得 $x \ge 2$，故 $P = [2, +\infty)$。

**【阶梯变式 3-2】**
设集合 $A = \{(x,y) \mid y = x^2\}$，$B = \{(x,y) \mid y = 2x\}$，则 $A \cap B$ 的元素个数为（   ）
A. 0     B. 1     C. 2     D. 无数个
**【解析】** C。代表元素是点，求交集即求两函数图象的交点。联立 $y=x^2$ 和 $y=2x$，解得 $(0,0), (2,4)$。共 2 个元素。

**【阶梯变式 3-3】**
设集合 $M = \{x \mid x = 2k+1, k \in \mathbb{Z}\}$，$N = \{x \mid x = 4k \pm 1, k \in \mathbb{Z}\}$，则 $M$ 与 $N$ 的关系是 ________。
**【解析】** $M = N$。$2k+1$ 表示所有奇数。$4k+1$ 覆盖了模 4 余 1 的奇数；$4k-1$ 覆盖了模 4 余 3 的奇数。两者并集即为所有奇数。

### 题型四：利用集合元素的互异性求参数
**【典例4】**
已知集合 $A = \{2, a, b\}$，且 $A = \{2a, 2, b^2\}$，求实数 $a, b$ 的值。

- **【思路点拨】** 两集合相等，对应元素相同。但列出方程组解完后，**必须代入原集合检验互异性**！
- **【规范解答】**
  因为 $A$ 中已有元素 $2$，故有 $\begin{cases} a = 2a \\ b = b^2 \end{cases}$ 或 $\begin{cases} a = b^2 \\ b = 2a \end{cases}$。
  情况一：$\begin{cases} a = 2a \\ b = b^2 \end{cases} \Rightarrow a=0, b=0$ 或 $a=0, b=1$。
  当 $a=0, b=0$ 时，$A=\{2,0,0\}$，违背互异性，舍！
  当 $a=0, b=1$ 时，$A=\{2,0,1\}$，满足。
  情况二：$\begin{cases} a = b^2 \\ b = 2a \end{cases} \Rightarrow 2b^2 - b = 0 \Rightarrow b=0$ 或 $b=\frac{1}{2}$。
  当 $b=0$ 时，$a=0$，舍！
  当 $b=\frac{1}{2}$ 时，$a=\frac{1}{4}$，$A=\{2,\frac{1}{4},\frac{1}{2}\}$，满足。
  综上，$(a,b) = (0,1)$ 或 $(\frac{1}{4}, \frac{1}{2})$。

**【阶梯变式 4-1】**
已知集合 $M = \{1, a\}$，$N = \{x^2, x\}$。若 $M = N$，则 $a = $ ________。
**【解析】** 集合相等则元素相同，由于 $N$ 中元素为 $x, x^2$ 且必含 1，故只能 $x=1$ 或 $x^2=1$。若 $x=1$，则 $N=\{1,1\}$ 违背互异性，舍去。若 $x=-1$，则 $N=\{1,-1\}$，此时 $a=-1$。

**【阶梯变式 4-2】**
已知集合 $A = \{x \mid x^2 - ax + 2 = 0\}$，若 $A$ 中只有一个元素，求实数 $a$ 的值。
**【解析】** 集合只有一个元素，意味着一元二次方程有两个相等的实数根，即判别式 $\Delta = a^2 - 8 = 0$。解得 $a = \pm 2\sqrt{2}$。

**【阶梯变式 4-3】**
设集合 $A = \{x \mid ax^2 - 3x + 2 = 0\}$。若集合 $A$ 中至多有一个元素，求 $a$ 的取值范围。
**【解析】** 分类讨论：
1) 当 $a=0$ 时，方程化为 $-3x+2=0$，$x=2/3$，集合有一个元素，符合！
2) 当 $a \neq 0$ 时，为一元二次方程。要使集合至多有一个元素（即无实数根或有两个相等实数根），需判别式 $\Delta = 9 - 8a \le 0$，解得 $a \ge \frac{9}{8}$。
综上，$a=0$ 或 $a \ge \frac{9}{8}$。

## 五、 当堂过关检测
> **测验要求**：高压极限输出，题量设置临界于“刚刚好做不完”。请拿出秒表的紧迫感！

### 【A组·基础限时秒杀】
1. 集合 $\{x \mid x^2 + 1 = 0, x \in \mathbb{R}\}$ 可化简为 ________。
   **【解答】** $\emptyset$（因为在实数范围内无解）。
2. 用列举法表示集合 $\{x \in \mathbb{Z} \mid -2 < x \le 1\} =$ ________。
   **【解答】** $\{-1, 0, 1\}$。
3. 若 $\{1, x, x^2\} = \{1, 2, y\}$，且 $x > 0$，则 $x+y =$ ________。
   **【解答】** $2+\sqrt{2}$。若 $x=2$，则 $x^2=4$，所以 $y=4$；若 $x^2=2$，则 $x=\sqrt{2}$，此时 $y=\sqrt{2}$。但由于集合相等，只能是 $\{1, \sqrt{2}, 2\}$ 对应，故 $x=\sqrt{2}, y=2$ 或 $x=2, y=\sqrt{2}$。但不论如何 $x+y=2+\sqrt{2}$。

### 【B组·中等综合提升】
4. 集合 $A = \{x \mid x = 2n, n \in \mathbb{Z}\}$，集合 $B = \{x \mid x = 4k, k \in \mathbb{Z}\}$，判断 $A$ 与 $B$ 的关系。
   **【解答】** $B \subsetneqq A$。因为偶数包含4的倍数，但4的倍数不包含所有偶数（如2）。
5. 已知 $A = \{ (x,y) \mid x+y=0 \}$，$B = \{ (x,y) \mid x-y=2 \}$，求 $A \cap B$。
   **【解答】** $\{(1, -1)\}$。联立方程组求解。
6. 已知 $M = \{ (x,y) \mid \frac{y-2}{x-1} = 1 \}$，$N = \{ (x,y) \mid y-2 = x-1 \}$，这两个集合相等吗？
   **【解答】** 不相等。$M$ 中 $x \neq 1$（由于分母），$N$ 是一条完整的直线。

### 【C组·拔高压轴挑战】
7. 若集合 $A = \{x \mid mx^2 - 2x + 3 = 0\}$ 中恰有两个互异实数，则 $m$ 的取值范围是 ________。
   **【解答】** 必须是一元二次方程且判别式大于0。所以 $m \neq 0$ 且 $\Delta = 4 - 12m > 0$。解得 $m < \frac{1}{3}$ 且 $m \neq 0$。
8. 定义新运算：对于非空实数集 $A, B$，定义 $A \oplus B = \{z \mid z=x+y, x \in A, y \in B\}$。若 $A = \{1, 2\}$，$B = \{0, 2, 4\}$，则 $A \oplus B$ 中元素的个数为 ________。
   **【解答】** 5个。可能的和为：$1+0=1, 1+2=3, 1+4=5, 2+0=2, 2+2=4, 2+4=6$。集合为 $\{1, 2, 3, 4, 5, 6\}$，共 6 个。（此题是经典高考创新题模型）。

## 六、 易错坑点防雷

- 🧨 **易错点1**：没看清“代表元素”。
  **正确做法**：拿到描述法的集合，**第一眼死盯竖线前面的符号**！是 $x$，是 $y$，还是 $(x,y)$？这直接决定了这是一条线段、一段值域，还是一群坐标点。
- 🧨 **易错点2**：求出含参集合的解后，狂喜交卷。
  **正确做法**：只要是集合里面带字母参数的题，解完以后**必须代回去看有没有重复元素**（互异性检验），北京卷特别喜欢在这里卡人！
