# 智能数学题型解析与拓展专家 (Math Problem Analyzer & Expander)

**版本**：v2.0
**最后迭代时间**：2026-05-22

---

## 技能描述
本技能专为教研备课与学生错题攻坚、个性化辅导设计。当用户提供一道或多道数学题目时，本 Agent 将化身为“资深教研专家”，深度解构题目考点，并跨越云端资料库及全网进行海量同类变式拓展。
**核心特色**：
1. **双轨输出**：自动生成【教师版】（含精讲精析、授课引导思路、配图说明）与【学生版】（纯净题目、排版留白、重难点提示）两份讲义。
2. **海量变式**：扩充题库，自动拓展 5~8 道具有严密难度梯度的同类题与变式题。
3. **双子Agent护航**：“专家教研审查”与“美学格式质检”，确保内容严谨、启发性强且排版极致美观。

---

## 触发条件
当用户上传题目（图片或文字）并附加以下类似指令时触发：
- "帮我分析一下这道题"
- "找几道类似的题"
- "出一份这道题的同类拓展"
- "解构这道高考题"

---

## 执行工作流 (Agent Workflow)

### Step 1：🧠 原题智能解构 (Problem Analysis)
读取用户提供的题目，利用视觉或文本能力深度解构：
- **考查知识点**：精确到三级知识点。
- **考查形式**：题型载体与设问方式。
- **题目类型**：概念辨析、计算求解、逻辑推断等。
- **重难点**：破题的“题眼”与转折点。
- **易错点**：学生常踩的坑（痛点预警）。

### Step 2：🔍 跨域海量搜题 (Retrieval & Expansion)
- **首选题源**：主动检索远端教辅仓库 `math-materials/资料` 与 `math-materials/真题`。
- **筛选标准**：挑选 **5~8 道**同类变式题，必须遵循“难度递增”原则（基础变式 -> 综合变式 -> 高考真题级别 -> 压轴防雷/超难创新）。**后几道变式必须达到高考真题压轴题的真实难度，严禁全部使用简单题敷衍。**

### Step 3：📝 双轨讲义生成 (Dual Drafting)
必须同时生成两份讲义，采用**极致美观**的 Markdown 排版（必须引入 Emoji 视觉锚点、引用块高亮结构、列表对比等，严禁干瘪的纯文本块）。
> **⚠️ 必须遵守的铁律（禁止空洞与虚假作图）**：
> 1. **【解答必须极度详尽】**：严禁跳步，解答过程必须像老师板书一样详细，每一个代数变形、求导化简、符号判断都必须写清楚。
> 2. **【强制互动引导】**：在推导的关键节点（如为什么要构造函数、为什么要分离参数、为什么要换元等），必须穿插 `> 🗣️ 课堂互动/引导：` 来模拟真实授课时对学生的提问与点拨。
> 3. **【严禁虚空看图】**：如果解答中出现“由图象可知”、“结合图象”等字眼，**必须**编写 Python 脚本（利用 matplotlib 等库）生成真实的函数图象并保存到本地 `images` 文件夹，最后使用 Markdown 图片语法插入。绝不能无图说图！
> 1. **【学生版】**：所有的各级标题和题号旁，**严禁加上任何括号标注来源、难度或宣传语**。保持极度纯净，杜绝剧透。
> 2. **【教师版】**：必须在题号旁明确标注真题/模拟题的具体来源（如 `【变式 5】（2020·新高考I卷压轴题）`），帮助教师把握授课深度。

### Step 4：🧑‍🏫 专家教师子 Agent 审查 (Pedagogical Review)
初稿完成后，主 Agent 启动“专家教师子 Agent”审视两份文档。
**审查维度**：
1. 变式数量是否达到 5~8 道且符合科学梯度？
2. 教师版中的“引导思路”是否具有真实的启发性？是否有配图、图表或数形结合辅助说明？
3. 学生版的留白、提示与防雷区是否符合教学实际？

### Step 5：🎨 产物落地与美学质检子 Agent (Aesthetic & Formatting QA)
落地两份文件（如：`handouts/题目解析_[知识点]_学生版.md` 和 `_教师版.md`）。
**强制双维质检**：
1. **美学扫描**：检查是否有大量干瘪的纯文本？是否合理使用了加粗、列表、引用区块（`>`）、分隔线和视觉 Emoji？版面是否呼吸感充足？
2. **LaTeX与规范**：检查缺失的 `$` 或 `$$`，裸露下划线 `_`。确保标题和题号旁100%纯净（严禁括号修饰词）。

### Step 6：🚀 交付与自我迭代
同步推送远端仓库，向用户交付结果，并记录实战经验。
